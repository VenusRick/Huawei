# 特征挖掘工具技术说明书

## 架构
唯一数据链（三任务共享）：Manifest -> Observation -> FeatureRecord -> RuleBundle
-> Prediction -> Evaluation/Report。应用/精细行为/匿名工具识别走同一条链，
区别只在 task config + manifest + feature spec + rule bundle。

- 解析层：PCAPReader（pcap/pcapng、纳秒精度、以太网 padding 截断、TLS 跨
  分段重组）+ SessionManager（canonical 五元组、SYN 期望序号、乱序缓冲、
  双向 FIN 回收、逐包事件转发 packet_listener）
- 观测层：src/features/runtime.py 共享提取入口（319 维会话特征 +
  M2 行为窗口 41 维）；R30 截断前缀标记
- 行为层：src/parser/context.py（5s/1s 窗、活动间隔切流段、K=3 槽位 +
  overflow 聚合、方向相对可见终端、无未来包）
- 特征选择：FeatureSelector（可 selection=none 对照）
- 规则学习：同一棵 CART 直接学真实标签并导出（_traverse_tree classes_
  映射）；XGBoost 仅作筛选器与离线对照，预测不进正式 DPI

## 使用（命令级）
```bash
python -m src.pipeline --mode validate-data --manifest data/task/xxx.jsonl --task app
python -m src.pipeline --mode mine --manifest data/task/train_val.jsonl \
  --task app --output output/run001     # 产 rules.yaml + bundle/ + analysis/
python -m src.engine.dpi_infer --rules output/run001/bundle \
  --pcap-dir data/test/ [-o predictions.json] [--terminal IP]
python -m src.pipeline --mode evaluate --truth data/task/truth.jsonl \
  --predictions predictions.json --task app --rules output/run001/bundle \
  --output output/run001/evaluation
python -m src.pipeline --mode revise-rules --rules output/run001/bundle \
  --edits review/edits.json --manifest data/task/validation.jsonl \
  --output output/run001_revision
python scripts/run_acceptance.py --output output/acceptanceXXX
```
