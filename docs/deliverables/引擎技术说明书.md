# 独立规则引擎技术说明书

## 规则包（bundle 三件套）
rules.json / selected_features.json / bundle_config.json；加载零训练库
依赖（不 import sklearn/xgboost）；bundle_config 含 task、标签词表、
置信度阈值、context 窗口配置（behavior 任务）。

## 匹配语义
- 严格 AND：全部条件满足才命中（score==1.0）
- not_exists 仅匹配空值（0 是合法观测）
- 缺失必需特征 -> 整条规则不匹配（缺失不零填）
- 阈值取 bundle 配置（不硬编码 0.7）
- 无命中输出 unknown（拒识计入评价完整分母）

## 行为窗口模式
bundle task=behavior 时按 context 配置重算窗口特征（与训练端同参同函数），
--terminal 指定可见终端（方向基准）。

## 资源与性能
PCAP逐包、PCAPNG逐块读取；正式runtime消费会话生成器并回收已结束会话。
已有会话/TLS资源上限与计数；长连接、高并发及全量端到端性能仍需另测。
当前小批次测量见《测试报告与部署手册.md》和本轮host_verify证据。

## 隔离性证据
- dpi_infer 源码零 sklearn/xgboost 引用
- 隔离目录（删 model.pkl/model.json）规则识别可启动（G04 验收）
- 改规则 -> 结果变；恢复 -> 复现（op 方向感知突变验证）

## 当前规则与计算依赖
统计规则confidence记录训练精确率，train_coverage另列；零覆盖规则不部署。
按priority升序匹配（树100、统计200），全部AND条件满足且达到bundle阈值才输出。
selected_features是训练筛选与人工编辑目录；`--on-demand`只计算可执行规则实际
条件引用的特征族。改规则后重新加载bundle会重新解析依赖，不能缓存旧依赖。
