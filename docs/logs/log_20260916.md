## 遇到的问题与解决方案
1. **相对路径软链死链**：`ln -s data/all_data/x` 基准是链接所在目录而非 cwd → 改绝对路径重建，解引用验证 12/12
2. **Monitor 超时连坐**：管线在监听命令里同步跑，10min 超时被杀整组 → setsid nohup 后台化 + tail -f 监听哨
3. **僵尸误判活**：ps 存在性检查对僵尸恒真 → 判活必须查 STAT
4. **kill 漏杀本体**：setsid fork 后 `$!` 是壳 PID → kill 后按命令名 ps 终查残留
5. **EXIT 取值坑**：`$?` 在管道后取的是 tail 的码 → 用 `${PIPESTATUS[0]}`
