## 4. S1：训练端和推理端都真正少算

1. 延续共享 runtime 和已修复的实际规则依赖裁剪，提供机器可读 fast feature profile。候选池先限定为最多32个低成本特征，首选16维版本；保留旧319维模式仅供兼容回归，不作为新默认训练路径。
2. 优先包数/字节数/时长/方向比例、包长均值和方差/极值、少量IAT和方向变化/简单突发计数；TLS可见标记等仅在真实观测到且解析成本合适时加入。默认不算近似熵/Hurst/频谱/高维BoW/不被规则引用的算子；不把源IP、源临时端口、文件/目录名当类别特征。
3. 现有 basic.extract_all 仍会算整族；按实际需要拆成可复用的小算子或增加 requested_features，不能“先提全部基础/319维再切列”。不复制两套特征公式。训练 mine 和独立 dpi_infer 使用相同 profile、前缀、缺失语义。
4. 首轮每会话最多32个真实观测包；若验证表明信息不足，再在同样输入上试64包。包数、算子依赖、特征定义版本、缺失语义写入bundle，独立CLI默认读取；禁止训练32包而CLI悄悄用500包。若必须兼容旧bundle，提供显式旧默认并测试。
5. 小样本逐值parity、前缀因果、未启用算子调用数=0、独立推理无训练库四项必须保持。性能基准使用同一固定会话集合和相同观测前缀，不能用少处理样本冒充每样本加速。

## 5. S2：在有限候选中优先改善规则识别

1. 从统一抽样数据缓存低成本特征，禁止为每个候选重复全量解析。只在train拟合特征选择器/浅树，validation选择配置与阈值；测试集不选模型、不选特征、不选样本。
2. 主候选最多4组：16/32维低成本profile × 不加权/类别均衡浅树。延续可解释CART→规则路线、自适应叶子、小深度，不增加神经网络、GNN或在线模型分支。必要时再给两个名额：64包前缀或一个验证驱动的廉价特征补充。
3. 检查每类规则覆盖、拒识原因与混淆，不只看总准确率。加权树的confidence不可冒充真实precision：保留真实未加权样本支持数、TP/FP、覆盖与precision。规则阈值、优先级、统计规则启停必须以实际独立规则引擎回放验证，不以XGBoost成绩替代。
4. 可在validation上校准规则阈值，预先固定少量阈值候选。先约束背景/逐类FPR和precision，再比较recall/accuracy；只有宏平均FPR低而某类超标，不算整体达标。不因旧值0.95而拒绝一切合理校准，也不为提召回忽视误报。
5. 候选无收益则不采纳。验证不足优先补小类/采集组，或补一个有依据的低成本特征，不能不断加深树。冻结方案后在预留测试批次完整输出独立DPI预测和复算指标。
