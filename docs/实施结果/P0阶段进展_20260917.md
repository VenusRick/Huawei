## 三、过程中的坑（已修）
1. replace 锚点不带缩进 → 插入块整体多 4 空格；且 replace 只影响首行拼接，
   后续行原本就对——去缩进必须只削首行层级（两步修复：全块左移后除首行右移）
2. 验收比对全字段含 match_time_ms（每次运行天然抖动）→ 假阴；改语义比对剔除 *_ms
3. 突变规则 value+1e9 没看 op 方向（<= 抬阈值反而更宽松）→ op 感知突变
   （> 加 1e12、< 减 1e12），断言识别数下降
4. run_acceptance 进程内复算 import src 失败（sys.path[0]=scripts/）→ 插 ROOT
5. fixture split 词 val/validation 不一致 → load 层别名归一化
